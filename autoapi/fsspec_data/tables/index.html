One partition on native local or S3 storage, with retained saved generations.

Reads and writes are synchronous. Storage must provide durable, atomic create-if-absent and consistent reads; capability support is not certification.

orphan_collector(*, retention_seconds: float, max_generations: int = 256, max_entries: int = 100000) → OrphanCollector[source]¶

Create a collector whose retention clock starts when it observes a file.

Keep this object between sweeps. Restarting resets retention. All published versions are retained; files in an unpublished generation are left alone.

class fsspec_data.tables.OrphanCollector(native: Any)[source]¶

Observe abandoned files and remove them after retention in occupied generations.

_native¶
collect(*, dry_run: bool = True) → CleanupReport[source]¶

Validate history, then list candidates; dry runs also track retention.

Keys in the report are relative to the table root. Validation or listing failures prevent deletion. A deletion failure may leave a partial sweep; rerunning is safe. Failure resets retention observations.
