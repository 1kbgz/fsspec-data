One partition on native local or S3 storage, with retained saved generations.

Writers are synchronous; readers also offer async methods. Storage must provide durable, atomic create-if-absent and consistent reads; capability support is not certification.

Watch committed rows without blocking the event loop.

Use an async context manager or await aclose() to drain pending reads. Checkpoints and terminal reasons match watch. Deadlines raise TimeoutError.

watch(*, start: WatchPosition | None = None, columns: collections.abc.Sequence[str] | None = None, batch_size: int = 1024, poll_interval: float = 0.1, idle_timeout: float | None = None) → TableWatcher[source]¶

Watch existing and newly published rows, or resume a saved position.

Requires an already published table with row progress. A new watch starts at the latest generation. A resume visits its saved generation and each successor; replacement ends the watch. Storage calls are synchronous.

orphan_collector(*, retention_seconds: float, max_generations: int = 256, max_entries: int = 100000) → OrphanCollector[source]¶

Create a collector whose retention clock starts when it observes a file.

Keep this object between sweeps. Restarting resets retention. All published versions are retained; files in an unpublished generation are left alone.

_native¶
collect(*, dry_run: bool = True) → CleanupReport[source]¶

Validate history, then list candidates; dry runs also track retention.

Keys in the report are relative to the table root. Validation or listing failures prevent deletion. A deletion failure may leave a partial sweep; rerunning is safe. Failure resets retention observations.

scan(*, columns: collections.abc.Sequence[str] | None = None, row_offset: int = 0, batch_size: int = 1024, row_limit: int | None = None, byte_limit: int | None = None) → fsspec_data.interchange.DecodedBatchStream[source]¶

Read only listed parts, checking each encoded part before decoding it.

Selection and output limits apply across parts. A part is read in full; max_part_bytes bounds encoded input, not decoder allocations.

async scan_async(*, columns: collections.abc.Sequence[str] | None = None, row_offset: int = 0, batch_size: int = 1024, row_limit: int | None = None, byte_limit: int | None = None, max_batch_bytes: int = 64 * 1024 * 1024, read_chunk_size: int = 1024 * 1024, deadline: float | None = None) → fsspec_data.async_scan.AsyncDecodedBatchStream[source]¶

Scan verified parts on demand, with I/O and decoding off the event loop.

A snapshot from snapshot_async uses native async S3 handles; synchronous snapshots use their existing filesystem on a worker. One encoded part is buffered at a time, bounded by max_part_bytes. max_batch_bytes is checked after decoding; internal decoder allocations are not a process memory cap.
