class fsspec_data.sink.DataWriter[source]¶

Bases: Protocol[_BatchReceipt_co, _PublicationReceipt_co, _RecoveryToken_co]

Positioned Arrow writes; receipts and recovery stay backend-specific.

Exact retries must not duplicate data. Forward positions are gaps; conflicting positions or key/payload reuse are conflicts. commit publishes and keeps the writer open; finish publishes and completes it. abort/close/drop discard pending work without undoing earlier commits. Clean context exit commits then closes; an exception aborts. Uncertain publications retain backend recovery information.

One configured table destination; existing ManifestTable conforms structurally.

Options and writer receipts are backend-specific. Implementations reject unsupported modes/options before writes. No inheritance or process-global registration is required. A protocol check verifies interface shape, not publication guarantees.
