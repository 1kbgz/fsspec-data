.. py:function:: scan_parquet_async(url: str, *, fs: fsspec.AbstractFileSystem | None = None, storage_options: collections.abc.Mapping[str, str | bool | int | float] | None = None, columns: collections.abc.Sequence[str] | None = None, row_offset: int = 0, batch_size: int = 1024, row_limit: int | None = None, byte_limit: int | None = None, max_range_bytes: int = 64 * 1024 * 1024, max_batch_bytes: int = 64 * 1024 * 1024, read_chunk_size: int = 1024 * 1024, deadline: float | None = None) -> AsyncDecodedBatchStream
   :async:


   Open a Parquet scan on native S3 or a filesystem with ``open_async``.

   ``deadline`` uses asyncio loop time. With ``fs``, only the opened file is owned
   by the scan; its reads and close must be awaitable, its size known, and seeks
   must be asynchronous or operate on a cached cursor without I/O.
