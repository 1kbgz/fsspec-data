.. py:function:: scan_parquet_async(url: str, *, storage_options: collections.abc.Mapping[str, str | bool | int | float] | None = None, columns: collections.abc.Sequence[str] | None = None, row_offset: int = 0, batch_size: int = 1024, row_limit: int | None = None, byte_limit: int | None = None, max_range_bytes: int = 64 * 1024 * 1024, max_batch_bytes: int = 64 * 1024 * 1024, read_chunk_size: int = 1024 * 1024, deadline: float | None = None) -> AsyncDecodedBatchStream
   :async:


   Open a native S3 Parquet scan. ``deadline`` uses ``asyncio`` loop time.

   ``url`` is ``s3://bucket/key`` or ``s3-rs://bucket/key``. Storage options use
   fsspec-rs's flat names, such as ``anon``, ``region`` and ``endpoint_url``.
   The stream owns its file. Decoding allocations are outside the buffer limits.
